**Simple Countdown Timer**
A lightweight, functional Countdown Timer built with Vanilla JavaScript, HTML5, and CSS3. This project demonstrates efficient DOM manipulation and state management for timing events.

**Features:**
Resume Capability: Unlike basic timers, this logic saves the current state when paused, allowing users to resume from the exact second they stopped.

Smart Validation: Prevents multiple timer instances from running simultaneously (no "speed-up" bug).

Dynamic UI: Real-time updates to the display using setInterval.

Reset Control: Easily clear the timer and input data with a single click.

**Technologies Used**
JavaScript (ES6+)

HTML5

CSS3

**Einfacher Countdown-Timer JavaScript**
Ein leichtgewichtiger und funktionaler Countdown-Timer, entwickelt mit Vanilla JavaScript, HTML5 und CSS3. Dieses Projekt demonstriert effiziente DOM-Manipulation und State-Management für Timing-Events.

**Funktionen**
Fortsetzungs-Funktion: Im Gegensatz zu einfachen Timern speichert diese Logik den aktuellen Status beim Pausieren. Nutzer können genau an der Sekunde fortfahren, an der sie angehalten haben.

Intelligente Validierung: Verhindert, dass mehrere Timer-Instanzen gleichzeitig laufen (vermeidet den "Beschleunigungs-Fehler").

Dynamische Benutzeroberfläche: Echtzeit-Aktualisierung der Anzeige über setInterval.

Reset-Steuerung: Setzen Sie den Timer und die Eingabedaten mit einem Klick einfach zurück.

**Verwendete Technologien**
JavaScript (ES6+)

HTML5

CSS3
